1. two types of packages-- 1.simple or regular dependencies, 2.developement dependencies
2. two types of package install-- 1.local and 2.Global
3. install regular packages: npm install package_name --or npm i package_name --or npm i package_name@version
4. install dev dependencies: npm install nodemon --save-dev
5. install global dependencies: npm i nodemon --global
6. run node file: node index.js
7. npm package versioning: major.minor.patch(eg 1.2.3)
8. version operators in package.json: 1.exact  1.2.3: installs 1.2.3 exactly
				      2.caret ^1.2.3: installs >= 1.2.3 and < 2.0.0
                                      3.tilde ~1.2.3: installs >= 1.2.3 and < 1.3.0
                                      4.wildcard * or x: installs the latest version published
9. check outdated packages: npm outdated
10. update package: npm update package_name
11. uninstall package: npm uninstall package_name
12. install packages after importing project: npm install 
13. npm i eslint prettier eslint-config-prettier eslint-plugin-prettier eslint-config-airbnb eslint-plugin-node eslint-plugin-import eslint-plugin-jsx-a11y eslint-plugin-react --save-dev
