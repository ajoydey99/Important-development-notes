Permissions
------------------------
** Permissions are split into three User Classes: 1. u (User/Owner)
                                                  2. g (group)
                                                  3. o (others)
                                                  4. a (all)
** There are three basic permission types: r (read), w (write), x(execute)
** Numeric mode uses a three-digit octal number to explicitly set permissions: Read(r) = 4
									       Write(w) = 2
                                                                               Execute(x) = 1
                                                         		       No permission (-) = 0
** Symbolic mode uses characters to add(+), remove(-) or explicitly match(=) permissions without altering the remaing flags
** rwx = read write execute (4+2+1 = 7)
** r-x = read ----- execute (4+0+1 = 5)
** r-- = read ----- ------- (4+0+0 = 4)
** drwxr-xr-x indicates a directory in Linux/Unix systems with 755 permissions
             -> rwx for [owner]
	     -> r-x for [group}
             -> r-x for [others/world]
** chmod [options/flags] [mode/permissions] [file_name}
** chmod -R 755 /path/to/directory = -R(recursive): changes permissions for a directory and all of its 
                                      underlying files and subdirectories simultaneously
** chmod -v 644 notes.txt = -v(verbose): outputs a diagnostic message for every processed file to easily
                            confirm the modifications
** chmod +x script.sh = Grants execute permissions to all user levels.
** chmod u+x script.sh = Grants execute permission specifically to the owner only.
** chmod g-w documennt = Revokes write permission from the group.
** chmod ug=rw,o=r file.txt = Sets User and Group to read/write and others to read-only

Nano text editor
-------------------------
** nano test.txt = create and open text file 
** File Operations=> ctrl + O = Save (Write Out) the current changes without exiting.
		     ctrl + X = Exit the editor. Nano will ask to save if you have unsaved changes.
 		     ctrl + R = Insert / Read another file's text into your current buffer.
** Editing & Clipboard=> ctrl + K = Cut the entire current line of text into the buffer.
			 ctrl + U = Paste (Uncut) the text previously placed in the buffer.
			 alt + 6 = Copy the current line.
			 alt + A  : Set a marker to select blocks of text using arrow keys.
		 	 alt + U  : Undo the last action.
			 alt + E  : Redo the last undone action.
** ctrl + S = save file 
** ctrl + G = display help text
** ctrl + ^ = select text/unselect

Vim text editor
-------------------------
** vi test.txt = create and open text file
** i = (insert mode) modify the file
** esc = escape to command mode from insert mode
** Saving and Quitting(Command-Line Mode)=> :w = save (write) the file.
                                            :wq = save and quit.
                                            :q! = quit without saving changes.
                                            :x = save and quit (faster eqivalent to :wq)
                                            :r filename.txt = read and append file to the current buffer
                                            :w filename.txt = create new file and save content
                                            :! linux_commands = use commands inside vim
 					    :e newfile.txt = open new buffer
                                            :enew = open new empty buffer
                                            :bp/bn = switch to buffer-previous/buffer-next
** Entering insert mode=> i = Insert text before the cursor.
                          a = Append text after the cursor.
                          A = Append text at the very end of the line.
                          o = Open a new line below the cursor.
                          O = Open a new line above the cursor.
                          v = entering visual mode
** Editing, Copying, Pasting=> x = Delete character under the cursor
                               dw = Delete from cursor to end of word
                               dd = Delete (cut) the entire current line
                               yy = Copy (yank) the current line.
                               p = Paste copied/cut text after the cursor
                               u = Undo last action
                               ctrl + r = Redo last undone action
** Cursor Movement (Normal Mode) => h = move left, j = move down, k = move up, l = move right
                                    w = Jumnp forward to start of next word.
                                    b = Jump backward to start of previous word.
                                    0 = Move to the beginning of current line 
                                    $ = Move to the end of current line
                                    gg = Go to the first line of the file
                                    G = Go to the last line of the file
                                    :<number> = Jump directly to a specific line number
Instructions
---------------------
** steps for navigating manual -> first type any man command, then hit h 
** anything written inside [] is optional
** [option]... means we can pass more than one option (eg: echo [string]... =  echo hello world)
** manual is broken into 8 different sections -
	 imp: 1. user commands, 
	      5. File formats and conventions
	      8.system admin commands(usaually only for root)
** type command tells us the type of the command, there are 4 types
	  1. /bin, /bin/usr, /usr/local/bin (executable program, bin means binary) [eg: type clear]
	  2. built-in shell command [eg: type cd]
	  3. a shell function
          4. an alias [eg: type cow]
** which command = to find the exact location of an executable [eg: which clear]
** help command is like manual for built-in shell command [eg: help cd]
